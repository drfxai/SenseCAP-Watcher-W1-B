# Maximus · Watcher Recovery

[بازکردن وب‌فلشر](https://drfxai.github.io/SenseCAP-Watcher-W1-B/?v=2.0.0) · [بسته کارخانه](https://drfxai.github.io/SenseCAP-Watcher-W1-B/downloads/watcher-factory-1.1.7.zip) · [راهنمای کامل](docs/RECOVERY.md)

بازیابی فریمور اصلی Seeed نسخه **1.1.7** برای **SenseCAP Watcher W1-B** با رابط مشکی، طلایی و آبی کهکشانی.

## فقط دو انتخاب

- **بکاپ دستگاه:** اتصال، خواندن و ذخیره اطلاعات فعلی با یک کلیک؛ بدون فلش‌کردن.
- **نصب دو مرحله‌ای:** پنجره راهنما برای بکاپ خودکار و نصب ESP32-S3، سپس ادامه نصب Himax.

برای مرحله اول از Chrome یا Edge دسکتاپ و کابل USB-C دیتا استفاده کنید. روی سیستم مالک، **COM6 برای ESP32** و **COM7 برای Himax** است. نصب مرورگری، برنامه و تنظیمات معمولی را جایگزین می‌کند و پارتیشن کارخانه موجود را حفظ می‌کند.

مرحله دوم، نصب‌کننده رسمی PowerShell را ارائه می‌دهد؛ اجرای آن روی ویندوز لازم است. دستور اصلی ابزار رسمی طبق خروجی مالک، انتقال Himax را تا ۱۰۰٪ انجام داده است. مرورگر اجرای PowerShell را مشاهده نمی‌کند؛ تأیید دستی کاربر جدا از نصب بررسی‌شده مرورگری ثبت می‌شود. روش مرورگری آزمایشی Himax در بخش پیشرفته همان پنجره موجود است.

اگر ESP32 قبلاً نصب شده، داخل پنجره نصب، گزارش موفق همان دستگاه را وارد کنید تا مستقیم از مرحله دوم ادامه دهید.

## فایل‌ها و پشتیبانی

جزئیات، فایل‌ها و گزارش عملیات زیر بخش جمع‌شونده «راهنما، فایل‌ها و گزارش» هستند.

- [نصب‌کننده Himax برای COM7](public/downloads/flash-himax-com7.ps1)
- [اصلاح S/N و EUI از بکاپ مخصوص مالک](public/downloads/repair-device-identity.ps1)
- [فایل مشخصات دستگاه](public/device-profile.json)
- [منبع، آدرس‌ها و SHA-256 فریمور](public/firmware/manifest.json)

**نصب فریمور، اعتبارنامه‌های پاک‌شده SenseCraft را بازسازی نمی‌کند.** فایل مشخصات شامل شناسه‌ها و KEY چاپی است که با درخواست مالک منتشر شده‌اند؛ باینری خصوصی بکاپ در مخزن قرار ندارد. شرح اصلاح شناسه‌ها، محدودیت‌ها و روش بازگردانی در [راهنمای کامل](docs/RECOVERY.md) است.

## توسعه

```sh
npm ci
npm test
npm run test:browser
python tools/package_firmware.py
npm run build
npm run dev
```

برای اولین اجرای تست مرورگر، `npx playwright install chromium` را اجرا کنید. Workflow مخزن بررسی‌ها، ساخت بسته و انتشار GitHub Pages را انجام می‌دهد.
